## 3. `ontologyRowSubjects:resolveRowSubject`: the three routes

- Two routes naming different ids → `conflicting_candidates` (471-476).
- An edge that would be dropped → `edge_would_be_dropped` (488-497).
- `local.m:1813` calls the function with no options, so `LocalIdentifierJoin` = **true** (default at 212).
